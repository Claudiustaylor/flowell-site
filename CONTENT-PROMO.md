## HASHTAG STRATEGY RULES

1. **TikTok: 4-6 hashtags max.** Mix 1-2 brand + 2-3 niche + 1 discovery (#fyp).
2. **Instagram: 10-15 hashtags.** Can go broader here. Mix brand + niche + community + discovery.
3. **YouTube Shorts: 5-8 hashtags.** Lean into #shorts + type beat tags.
4. **Rotate hashtags.** Don't use the exact same set every post. TikTok's algorithm flags repetition.
5. **Niche over broad.** #afrobeatsproducer beats #music every time. Target artists, not general audience.
6. **Trending beats evergreen.** #typebeat is always trending in the producer community. Use it consistently.
7. **Comment > caption for links.** TikTok suppresses posts with links in captions. Put "link in bio" instead.
8. **First 3 seconds matter.** The caption is secondary. Lead with the audio/visual hook.
